# Audio-Podcast-Gear-Guide-Directory-Portal

SONORA — Audio Podcast Gear Guide & Directory Portal

Single-page responsive website based on the supplied project brief:
Build an electronics web shop / guide and directory for Audio Podcast Gear, including
360° product views, audio specification comparisons, noise-cancellation guidance and
instant warranty registration.

14 sections:
1 Hero
2 Studio Reality
3 Signal Lab
4 Featured Hardware
5 Spec Comparison
6 360° Product Lab
7 Buyer Guides
8 Noise-Cancellation Guide
9 Directory
10 Spatial Audio Index
11 Setup Blueprint
12 Warranty Center
13 FAQ
14 Find Your Setup

Four signature animated experiences:
- Live frequency/waveform spectrum
- 3D floating product with orbital rings
- 3D spatial cube
- Hero orbital hardware visualization + pointer tilt

Forms are demo-only. Product imagery uses Pexels-hosted images.
